
# CNN Fire Image Classification

Project Computer Vision: klasifikasi citra kebakaran dan
non-kebakaran menggunakan Convolutional Neural Network (CNN).

## Tujuan
- Membangun model klasifikasi citra berbasis CNN.
- Melakukan preprocessing dan pelatihan model.
- Mengevaluasi model menggunakan metrik klasifikasi.
- Menguji prediksi pada gambar baru.

## Teknologi
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Scikit-learn

## Struktur Project
- `dataset/`: dokumentasi dataset
- `notebooks/`: eksperimen
- `src/`: program
- `results/`: hasil evaluasi
- `report/`: laporan UTS

## Status
Tahap persiapan lingkungan dan struktur project.

## Catatan
Hasil evaluasi akan ditambahkan setelah eksperimen dijalankan.
Dataset harus diperoleh sesuai sumber dan ketentuan lisensinya.
