# Outline Artikel Medium

## Judul
Membangun CNN untuk Klasifikasi Citra Fire dan Non-Fire dengan Dataset Publik Ringan

## Struktur Artikel
1. Latar belakang project UTS Computer Vision.
2. Tujuan dan batasan project.
3. Dataset publik Mendeley: 1.000 gambar sintetis, 500 Fire dan 500 Non-Fire; arsip sekitar 89,5 MB.
4. Cara download otomatis melalui Python.
5. Preprocessing dan split train/validation/test.
6. Arsitektur CNN dan parameter training.
7. Hasil eksperimen: masukkan angka aktual dan grafik setelah training.
8. Analisis kesalahan dan keterbatasan dataset sintetis.
9. Cara menjalankan project dan tautan GitHub.
10. Atribusi dataset CC BY 4.0.

Jangan mengklaim hasil evaluasi sebelum script training dan evaluasi dijalankan. Jelaskan dengan tegas bahwa dataset ini sintetis dan bukan validasi untuk keselamatan kebakaran di dunia nyata.
